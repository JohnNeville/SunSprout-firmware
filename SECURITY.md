# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub's
[private vulnerability reporting](https://github.com/JohnNeville/SunSprout-firmware/security/advisories/new)
rather than a public issue.

Include the firmware version (shown in Home Assistant or in the release name), what you observed,
and how to reproduce it. I'll acknowledge reports as soon as I can.

## Software bill of materials

Each release includes an SPDX SBOM (`.spdx`) for every firmware image, listing ESPHome, ESP-IDF,
external components (with exact commits) and libraries.
